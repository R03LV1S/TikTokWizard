================================================================================
                    HOW TO USE THE _PROJECTS FOLDER
================================================================================

Each song/project gets its own folder inside `START HERE\_Projects\`.

EXAMPLE PROJECT:
----------------
- `PaoPao - Grax` is included as an example (audio + lyrics).
- A rendered video file is not included to keep the download smaller.
  You can generate your own video by running TikTok Wizard.

QUICK START:
------------
1. MAKE A NEW PROJECT FOLDER
   - Create a new folder and name it `Artist - Song` (or any name you prefer).
   - You can also copy the `PaoPao - Grax` folder and rename it.

2. ADD YOUR FILES
   - Add your song/audio file (for example, `.mp3`).
   - Add a lyrics `.txt` file.
   - Use the PaoPao example lyrics text file as your formatting reference.

3. WRITE LYRICS LIKE THE EXAMPLE
   - Put each lyric line/phrase on its own line in the `.txt` file.
   - Keep lines short and readable.
   - Use parentheses for echoes, ad-libs, or background vocal parts,
     for example: `(Gracias, gracias)` or `(Hello?)`
   - Match the same simple structure and style as the example lyrics file.

4. RUN TIKTOK WIZARD
   - Open the `START HERE` folder and double-click the launcher for your OS:
     - Windows: `Double-Click to Start (Windows).bat`
     - Linux:   `Double-Click to Start (Linux).sh`
     - macOS:   `Double-Click to Start (Mac).command`
   - Select your project and follow the prompts to create your video.

FOLDER NOTES:
-------------
- Keep your audio, lyrics, and generated video files together in your project folder.
- Shared assets live in `_Assets\`.
- You can make as many project folders as you want, one per song/project.
================================================================================
