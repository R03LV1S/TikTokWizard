================================================================================
                    SAMPLE PROJECT: PaoPao - Grax
================================================================================

This folder is a complete WORKING EXAMPLE showing how your song folder should look.

WHAT IS IN HERE:
----------------
1. PaoPao - Grax (Trance Remix).mp3
   - The master audio track (.mp3 or .wav).

2. paopao_grax.txt
   - The original lyrics file (.txt).
   - Each line in this file corresponds to one subtitle line on the screen.

3. lyrics_easy.txt (Easy Lyrics Editor)
   - Human-friendly editable lyrics with timestamps.
   - Open this file in Notepad or press 'E' in TikTok Wizard to fix words or timing!

4. PaoPao - Grax v1.mp4
   - The rendered video output created by TikTok Wizard.
   - When you render again, it creates `v2.mp4`, `v3.mp4`, etc. Never overwriting!

HOW TO CLONE THIS AS A TEMPLATE FOR YOUR OWN SONG:
--------------------------------------------------
1. Go back to `_START HERE/_Projects/`
2. Copy the `_Artist_Song` template folder (or copy this folder).
3. Paste it and rename the folder to your Artist and Title:
      e.g. `Bad Bunny - Monaco`
4. Replace the .mp3 with your song's .mp3.
5. Replace the .txt with your song's lyrics.
6. Launch TikTok Wizard (Desktop shortcut or `_START HERE/Windows/`).
7. Select your song from the menu and start rendering!
