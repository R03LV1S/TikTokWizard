DEFAULT ASSETS (BACKGROUNDS & FONTS)
====================================

This folder holds all shared assets used across your TikTok videos, use the default format/option so your posts maintain a consistent brand look using the default profile (option 1).

Rename ONLY (1) file in each folder as "default" to assign it to the default profile (example: default.mp4, default.wmv, default.mkv, default.jpg, default.png, default.gif, etc.)

FOLDER BREAKDOWN:
-----------------
1. Backgrounds/
   - Videos/   -> Put your background videos here.
   - Pictures/ -> Put background images here.
   - Gifs/     -> Put animated background gifs here.

2. Fonts/
   - Put your custom subtitle fonts here (.ttf, .otf).

NOTE:
Backgrounds are ALWAYS loaded from `_Assets/Backgrounds/` (Videos, Pictures, or Gifs). 
Project folders under `_Projects/` should only contain your song audio (.mp3/.wav) and lyrics (.txt).
