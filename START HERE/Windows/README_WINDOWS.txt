HOW TO USE ON WINDOWS:
=======================
1. Double-click the file named:
   "Double-Click to Start TikTok Wizard.bat"

2. That's it! The script will automatically set everything up for you.

REQUIREMENTS:
- Python 3.10+ (Check "Add to PATH" when installing from python.org)
- FFmpeg (Install via: winget install Gyan.FFmpeg)
