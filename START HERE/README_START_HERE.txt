HOW TO START TIKTOK WIZARD:
============================

1. Double-click the launcher for your system right here in this folder:
   - Windows: "Double-Click to Start (Windows).bat"
   - Mac:     "Double-Click to Start (Mac).command"
   - Linux:   "Double-Click to Start (Linux).sh"

   (Or open the "Windows", "Mac", or "Linux" folder if you prefer)

2. Your song projects live in:
   "_Projects/"
   - Put your song folder inside "_Projects/" with your .mp3 and lyrics .txt.
   - See "_Projects/PaoPao - Grax" for a complete working example!

3. Everything else is handled automatically:
   - TikTok Wizard automatically aligns lyrics word-by-word.
   - Choose a profile, visualizer, background, and render.

Enjoy making viral videos!
