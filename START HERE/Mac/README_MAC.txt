HOW TO USE ON MAC:
===================
1. Double-click the file named:
   "Double-Click to Start TikTok Wizard.command"

2. If macOS says it can't open it because it's from an unidentified developer:
   - Right-click the file -> Click "Open" -> Click "Open" in the pop-up.

REQUIREMENTS:
- FFmpeg (Install in Terminal via: brew install ffmpeg)
